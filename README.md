# Random Headline Generator

A simple Python mini project that generates random news headlines using the `random` module.

## Features

- Generates random headlines
- Uses random subjects, actions, and topics
- Allows the user to generate multiple headlines
- Simple command-line interface

## Concepts Used

- Python lists
- `random.choice()`
- `while` loop
- `if` statement
- `input()`
- `break`
- f-strings
- `.strip()`
- `.lower()`

## How to Run

Make sure Python is installed.

Run:

```bash
python headline_generator.py
